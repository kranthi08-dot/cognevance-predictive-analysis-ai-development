# Project Report: Predictive Analytics & AI Model Deployment

## 1. Problem
Predict which telecom-style customers will churn, so retention teams can act early.

## 2. Data
50,120 rows, 13 features and a binary target (33.5% churn). It includes about 1-2% missing values in `total_charges`, `age` and `region`, plus 120 duplicate rows. The data is synthetic, generated by `src/generate_data.py`.

## 3. Preprocessing and feature engineering
- Cleaning: removed duplicates and invalid tenure or charge values (120 rows removed).
- Imputation: median for numeric, most-frequent for categorical.
- Scaling: standardisation. Encoding: one-hot.
- Engineered features: average monthly spend, charge ratio, support calls per year, late payments per year, new-customer flag, high-support flag, fibre and month-to-month interaction, charges per service, and tenure bucket.

## 4. Models
Logistic Regression, Random Forest, Histogram Gradient Boosting and a Multilayer Perceptron neural network (64-32 units, early stopping). All use the same pipeline, an 80/20 stratified split and 3-fold CV on the training set.

## 5. Results
| Model | Accuracy | Precision | Recall | F1 | ROC-AUC | CV AUC |
|---|---|---|---|---|---|---|
| Logistic Regression | 0.7342 | 0.6394 | 0.4716 | 0.5428 | 0.7751 | 0.7853 |
| Neural Network (MLP) | 0.7326 | 0.6309 | 0.4839 | 0.5477 | 0.7715 | 0.7797 |
| Gradient Boosting | 0.7317 | 0.6327 | 0.4725 | 0.5410 | 0.7707 | 0.7803 |
| Random Forest | 0.7326 | 0.6400 | 0.4591 | 0.5346 | 0.7650 | 0.7729 |

The best model by ROC-AUC is Logistic Regression. Lowering the threshold from 0.5 to 0.303 raises recall from 0.47 to 0.77 (precision 0.52, F1 0.62), which suits retention campaigns where missing a churner costs more than a wasted offer.

Top drivers (permutation importance): contract type, tenure, total charges, monthly charges, support calls.

## 6. Deployment
A Flask REST API serves the saved pipeline (`/predict`, `/predict_batch`, `/health`) with input validation and a web form. It ships with a Dockerfile and a Procfile. Three automated tests pass.

## 7. Dashboard
`outputs/dashboard.html` shows KPI cards, the model comparison table, ROC curves, confusion matrix, feature importance, risk-decile calibration and sample predictions.

## 8. Limitations and next steps
Synthetic data, so results will differ on real data. Next steps: hyperparameter search, SHAP explanations, model monitoring and drift checks, and a TensorFlow or PyTorch deep model.
